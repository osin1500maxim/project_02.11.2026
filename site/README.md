# АвтоОценка — сайт для модели оценки автомобиля по фото

## Структура

```
site/
├── app.py              бэкенд: страницы и API (FastAPI)
├── core.py             работа с моделями: фото → распознавание → цена → аналитика → PDF
├── static/             фронтенд
│   ├── index.html      страница «Оценка»
│   ├── about.html      страница «О проекте»
│   ├── style.css       оформление
│   ├── app.js          логика страницы «Оценка» (отправка формы, графики)
│   └── vendor/chart.umd.js   библиотека графиков (лежит локально, без внешних CDN)
├── models/             ← сюда кладутся файлы после обучения
├── requirements.txt
├── Dockerfile          образ для сервера
├── docker-compose.yml  сайт + Caddy (HTTPS)
├── Caddyfile
└── .env.example        домен
```

Как это работает: браузер отправляет фото, год и пробег на `POST /api/estimate`. Сервер считает
цену и возвращает JSON, по которому страница рисует результат и графики. PDF скачивается по ссылке
`/api/report/<id>`. Документация API открывается по адресу `/api/docs`.

## 1. Положите модели

Скопируйте в папку `models/` файлы из папки, где запускали `train.py`:
`car_model.pt`, `price_model.joblib`, `train.py`, а также, если есть, `metrics.txt` и `training_curves.png`.

## 2. Запуск на своём компьютере

```
cd site
pip install -r requirements.txt        # torch у вас уже установлен
uvicorn app:app --reload
```
Откройте http://127.0.0.1:8000

## 3. Выкладка на сервер (VPS без видеокарты)

**Сервер.** Ubuntu 22.04 или 24.04, минимум **2 ядра и 4 ГБ памяти**, 20 ГБ диска.
Подойдёт VPS у Timeweb Cloud, Selectel, REG.RU и т.п.

1. Подключитесь к серверу (в PowerShell): `ssh root@IP_СЕРВЕРА`
2. Установите Docker:
   ```
   curl -fsSL https://get.docker.com | sh
   ```
3. Скопируйте папку `site` на сервер. Удобнее всего через программу WinSCP, либо командой с вашего компьютера:
   ```
   scp -r site root@IP_СЕРВЕРА:/opt/
   ```
4. На сервере запустите:
   ```
   cd /opt/site
   cp .env.example .env
   docker compose up -d --build
   ```
   Первая сборка займёт 5–15 минут: скачиваются PyTorch и модель удаления фона.
5. Откройте `http://IP_СЕРВЕРА`, сайт должен работать.

**Домен и HTTPS.**
1. Купите домен и в настройках DNS создайте запись `A`, указывающую на IP сервера.
2. В файле `.env` раскомментируйте строку и впишите домен: `DOMAIN=ваш-домен.ru`.
3. Выполните `docker compose up -d`.

Caddy сам получит бесплатный HTTPS-сертификат.

**Полезные команды на сервере.**
```
docker compose logs -f app        # логи сайта
docker compose restart app        # перезапуск
docker compose up -d --build      # обновить после изменения кода или моделей
```

Если на сервере медленно скачивается PyTorch, в `Dockerfile` замените строку установки torch на
зеркало: `RUN pip install torch torchvision -f https://mirrors.aliyun.com/pytorch-wheels/cpu`.

## Безопасность и нагрузка
- Принимаются только изображения до 10 МБ. Фото не сохраняется на диск, PDF хранится в памяти 1 час.
- Одновременно считается не больше `MAX_PARALLEL` оценок (по умолчанию 2), остальные ждут в очереди.
- Одна оценка на процессоре занимает 2–5 секунд.
